上面的数据只来自当前浏览器。要看所有访客的访问数据，推荐用 Cloudflare Web Analytics：

  1. 打开 Cloudflare 控制台 → Web Analytics
  2. 点「Add a site」，输入 www.cbtidd.top
  3. 复制给你的 beacon JS 脚本，粘到 index.html 的 </body> 前
